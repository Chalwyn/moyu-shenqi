# 摸鱼神器

把本地 TXT 小说排成钉钉或飞书风格群聊的离线阅读器。

GitHub 仓库：[Chalwyn/moyu-shenqi](https://github.com/Chalwyn/moyu-shenqi)。

直接使用可前往 **[下载发行版](https://github.com/Chalwyn/moyu-shenqi/releases/latest)**，在 Assets 中下载 HTML 或 ZIP。

## 本地使用

1. 下载仓库中的 **[摸鱼神器.html](./摸鱼神器.html)**，放到一个固定目录。
2. 使用 Mac Chrome 或 Edge 打开，点击“+”导入 TXT，也可以拖入文件或粘贴正文。
3. 打开“聊天人物与回复”，设置联系人姓名和自己的预设回复，点击“保存并应用”。

无需账号、油猴、网络或安装依赖。发行附件提供可直接打开的 `moyu-shenqi.html`，以及打包下载的 `moyu-shenqi-v1.0.0.zip`；ZIP 解压后为 `摸鱼神器.html`。

完整操作与限制见 **[使用说明](./使用说明.md)**。

## 功能

- **TXT 阅读**：编码识别、章节切分、长章节续节、本地文档库。
- **联系人轮流发言**：导入或粘贴姓名名单，按顺序分配小说片段，保留原文内容与顺序。
- **右侧预设消息**：按配置间隔自动穿插自己的话语，可修改显示名称、回复内容和间隔，也可关闭。
- **手动回复**：点击原文消息后在该位置回复；未选中时按当前阅读位置插入。`Enter` 发送，`Shift + Enter` 换行，中文输入法选字时的回车不会发送。
- **每本书独立保存**：联系人、预设回复、阅读进度、书签和手动消息保存在本机；手动消息按章节归档。
- **两套外观**：钉钉与飞书风格，支持字号、行距、字体、工作资料标题和暂离显示。
- **阅读辅助**：全文搜索、书签、左右键切章，以及手机端章节抽屉。

## 构建

安装 Node.js 后，在仓库目录执行：

```sh
node build.mjs
```

无需安装 npm 依赖。构建会将页面、样式和脚本内联，生成仓库成品 `摸鱼神器.html`。

## 数据与参考

内置《雨停之前》为本项目原创示例。导入的小说、聊天配置和手动消息只保存在当前浏览器本机存储中，不会写回原始 TXT，也不会随 HTML 文件一起迁移。请保留原始小说，尽量使用同一浏览器和固定文件路径；清理浏览数据可能删除文档与进度。

界面参考 [BiliShu](https://github.com/Jack-Cherish/BiliShu) 的会话换肤思路，飞书布局参考其 v0.6.1 源码。摸鱼神器是独立实现的本地阅读器，非钉钉、飞书或 B 站官方产品，不连接这些服务。
